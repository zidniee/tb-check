# Local Agents Configuration

This `.agents` directory contains custom skills and subagents specific to this workspace.

## Directory Structure

- `skills/`: Contains custom skills (specialized instructions and scripts). Each skill should be in its own directory containing a `SKILL.md` file.
- `agents/`: Contains custom subagents (specialized autonomous agents). Each agent should be in its own directory containing an `AGENT.md` file.

## Usage

Once created, Antigravity will automatically load and have access to these skills and agents when operating within this workspace.
